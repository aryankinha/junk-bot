## Shared rules and ownership

- Flags: gate_clarity, gate_preview, material_tiers, horde_scaling, jackpot_gate, all false. ui_v2 reused; gate_clarity selects that presentation without changing canonical defaults. Mob-dependent features require existing mob_stream in the review/test bundle. No silent activation of E1–E5 or gameplay in normal builds.
- Pure `sim.hook` controller (RefCounted) owns run-only material/chain/encounter state. Existing save root/version/paths/economy/ads unchanged. GameData loads tiers.json. UI reads state/events; it never grants tier progress or changes a gate value.
- One player-facing metric: **STREAM POWER = weighted nominal drone units in one weapon-family volley**. It is explicitly not live node count or DPS. Use the family icon/name where needed. A pure shared resolver computes input→output, used by simulation, previews and rational bot.
- Resolve a launch cohort atomically at the first member's gate crossing, choosing that panel from its position; mark every sibling/copy. +N adds N units once to that volley, ×N multiplies its units. This is an explicit flag-only semantic change; old N-per5-arrivals remains unchanged with gate_preview off. Incoming preview reads the leading eligible cohort; a fallback new-volley estimate is labelled as an estimate. Cohort state/masks survive cap compaction.
- Direct payload accounting: new material mode first fills real slots and bounded heavier units, then redirects only residual units/damage to a ledger. Retained payload and progress credit are disjoint. Test requested=retained+converted (with traps/hits/expiry separately recorded). Do not claim conservation of splash geometry, DoT, pierces or spatial coverage.
- Simplify attribution to the primary active family if recent-damage attribution would destabilize the loop; record exact rule. Chain bonuses are separately logged progress bonuses. Damage pauses credit application briefly, storing earned surplus rather than deleting it. Tiers never decrease; startsT1 each run. No new saved currency or meter.
