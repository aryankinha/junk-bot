# Scrap Dragon specification
Portrait Android 3D gate runner. Drag relative to steer; auto-forward and auto-fire. Choose visible parts, grow Tiny → Battle → Monster, dodge hazards and telegraphed attacks, defeat the three-phase Scrap Titan. Spend earned Cogs in the Hangar and retry immediately. Junkyard only, levels 1–5, local daily seed and Codex. Score: collected scrap plus boss and streak rewards. Target arm64 mid-range phones at 60 fps, ≤150 draw calls, ≤400 MB memory, <120 MB install (aim <60 MB), first playable <2.5 seconds. Compatibility renderer, fixed 60 Hz pure simulation, seeded RNG streams; balance lives in data JSON. Shared vertex-colour palette and procedural fallback art from the supplied asset plan. Physical device acceptance is pending until a phone is connected.
