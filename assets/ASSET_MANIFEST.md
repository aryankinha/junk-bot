# Asset manifest

All shipping models use the procedural fallbacks authorized by 02_ASSET_PLAN section 1.7. No pack model is shipped. Candidate pack licences were researched before implementation; attempted Kenney archive URLs returned HTML rather than usable ZIP data. The all-pack download/import portion of M0 remains unfulfilled.

Every chassis exposes the 16 named socket positions from the architecture. One merged vertex-colour material covers robot, enemies and scenery; each removable attachment is a separate surface. Models are generated by src/view/mesh_factory.gd.

Chassis (three stages): stacked boxes, wheels, visor, shoulders and stage-3 horns. Scrapper/Gunner/Bruiser/Elite use procedural chassis with size variants. Titan uses a merged body with independently removable plate, core and grabber arm. Road, lane paint, wrecks, scrap, bullets and debris are original procedural geometry. No texture downloads, skinning, normal maps, or unlicensed pack fragments. Screenshot: results/asset_spike.png; measured triangle counts: results/asset_triangles.json.
